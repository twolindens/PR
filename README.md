# PR

A public repository with visuals that explain complex topics.

Vote on existing or submit new topics on the [Issues](https://github.com/twolindens/PR/issues) dashboard to request an explainer visual. Our team reviews the issues regularly and creates easy to understand visual content to explain the topic. 

Content List:
- VMSContainer: Visual comparison diagram between Virtual Machines and Containers
- Sustainable Operations Model: A strategic view about the operational model for a community hub to achieve financial sustainability. 
- BlockchainApIntro and BlockchainSmartContract: Presentations that illustrate the building blocks of a practical blockchain application.
